# Project Fee-Pivot: FNBT Data Analyst Portfolio

## Overview
End-to-end data pipeline for First National Bank Texas (FNBT) focusing on overdraft revenue and fee transparency.

## Architecture
- **Source:** Synthetic Multi-Vendor (Fiserv/Compass)
- **Warehouse:** Google BigQuery
- **Transformation:** Python/Pandas & SQL
- **BI:** Looker Studio

## Key Achievements
- Successfully resolved 70 injected data anomalies.
- Automated reconciliation across simulated vendor systems.
- Developed a Service Charge Reliance Index for executive oversight.
